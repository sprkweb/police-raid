# Алгоритм байесовского бота

Спецификация мозга по умолчанию: `createBotBrain('bayesian')`. Имена совпадают с символами TypeScript в этой папке. Старая «эгоистичная» политика — `heuristicBrain.ts`; её можно включить для бенчмарков.

## Зачем миры, а не подозрение на каждого

Роли кротов — это *множество*. Если кротов двое, «A на 50% крот» и «B на 50% крот» не независимы. Когда рейд из двух человек возвращает два саботажа, единственная согласованная гипотеза — что это и есть пара кротов; остальные чисты. Независимые счётчики этого не умеют. Поэтому бот хранит дискретное распределение по **мирам**.

Мир — один возможный набор кротов размера `moleCount`. Наблюдатель всегда считает себя полицейским, поэтому миры — это `moleCount`-подмножества остальных `N − 1` мест (`enumerateWorlds`). Для 5 игроков / 2 кротов это C(4,2) = 6 миров; для 8 игроков / 3 кротов — C(7,3) = 35.

`WorldBelief.probability` — это `P(W)`. В начале матча априор равномерный.

## Чего бот не видит

Боты крутятся на хосте, но байесовская политика написана так, будто есть только **публичная** информация плюс своё место:

- Чужие скрытые карты рейда не используются.
- Полиция не видит чужие роли.
- Кроты знают истинный набор кротов **только** при выборе действия в рейде (`trueMoleIds`). Предложение состава и голос идут в пространстве миров полицейского (камуфляж).

`GameEngine` держит приватный `observationLog` (`BotObservation[]`), потому что в проекции `GameState` исчезают отклонённые составы и голоса до закрытия урны. Этот лог клиентам не уходит.

## Теория сознания (level-1)

Два слоя, без рекурсии:

| Слой | Функция | Свидетельства |
| --- | --- | --- |
| Level-0 | `beliefsFromRaids` | Только исходы рейдов (`k` карт саботажа). |
| Level-1 | `level1BeliefsFromHistory` | Level-0, затем предложения и голоса, оценённые **вложенным level-0 мозгом**. |

Когда ходит игрок `V`, спрашиваем: что сделал бы коп (или крот в мире `W`) на месте `V`, используя **только** `beliefsFromRaids` с точки зрения `V` и историю *строго до* этого действия (`nestedCopProposeTeams`, `nestedCopVote`, `nestedMoleProposeTeams`, `nestedMoleVote`)?

Вложенный мозг **не** запускает level-1 на остальных. Это было бы level-2+.

Свои propose/vote считают `cleanProbability` по **level-1** posterior. Вложенные акторы — по **своему** level-0.

## `cleanProbability`

```
P_clean(T) = Σ P(W) по мирам, где T ∩ W = ∅
```

Реализация: `cleanProbability(beliefs, team)`. Значения ≤ `CLEAN_ZERO_EPS` считаются нулём.

## Наблюдение рейда (жёсткий сигнал)

Команда `T` вернула `k` саботажей. Мир с `m = |T ∩ W|` кротами на составе получает `raidLikelihood(m, k)`:

- `k > m` → 0 (невозможно)
- иначе биномиал: `C(m,k) * SABOTAGE_PRIOR^k * (1 − SABOTAGE_PRIOR)^{m−k}`

`SABOTAGE_PRIOR` (`α = 0.85`) — **только** модель наблюдения. Успешный рейд (`k = 0`) не обнуляет миры с кротами на составе (вес `(1 − α)^m`).

Дальше нормализация (`normalizeBeliefs`). Если все веса 0 — равномерный fallback.

## Вложенные политики (level-0 actor)

Те же правила, что у нас, но на raid-only `P_clean` этого игрока.

### Предложение копа — `nestedCopProposeTeams`

Все составы нужного размера, содержащие `V`. Argmax `P_clean`. Ничьи остаются множеством (правдоподобие совпадает с любым из них).

### Голос копа — `nestedCopVote`

1. Hammer: `consecutiveRejections >= N − 1` → `Approve` (ещё одно отклонение — победа кротов по лимиту).
2. `V` в составе → `Approve`, если только не `P_clean == 0`.
3. `V` вне состава → `Approve` только при `P_clean >= CLEAN_VOTE_THRESHOLD` (0.75).

### Предложение крота — `nestedMoleProposeTeams`

Argmax `P_clean` среди составов, где есть `V` **и** пересечение с `W`. Предложивший крот всегда берёт себя, поэтому инфильтрация на propose часто автоматическая; основной сигнал — голос.

### Голос крота — `nestedMoleVote`

`Approve`, если `T ∩ W ≠ ∅`, иначе `Reject`. Вложенный крот на hammer **не** обязан жать Approve: чистый состав на последнем отклонении — его победа.

## Мягкие правдоподобия (обновление level-1)

Константы: `COP_ACTION_MATCH = 0.95`, `COP_ACTION_MISMATCH = 0.05`, `MOLE_ACTION_MATCH = 0.85`, `MOLE_ACTION_MISMATCH = 0.15`.

После предложения `T` автором `A` и после каждого голоса `Vote_V`, для каждого мира `W`:

- Если `A`/`V` ∉ `W` (в этом мире коп): совпало с nested cop → 0.95, иначе 0.05.
- Если `A`/`V` ∈ `W` (крот): совпало с nested mole → 0.85, иначе 0.15.

Голоса перемножаются по всем игрокам, затем нормализация.

## Наши решения (level-1)

Кроты **камуфлируются**: propose и vote — cop-policy на *нашем* level-1 `P_clean`, включая hammer `Approve`.

- **Propose** (`chooseProposedTeam`): argmax `P_clean` среди составов нужного размера с собой. Ничьи — `pickTiedTeam` / `random`.
- **Vote** (`chooseTeamVote`): `nestedCopVote` на level-1 posterior.
- **Рейд, полиция**: всегда `Support`.
- **Рейд, крот**: `Sabotage`, если это место в `designateSaboteurs`, иначе `Support`.

## Конвенция саботажа — `designateSaboteurs`

Среди кротов **на этом рейде** назначаются `need = min(requiredSabotages, m)` саботажей:

1. Кто из них уже срывал — в порядке первого срыва (`priorSaboteurs`).
2. Если никто из кротов на этом рейде ещё не срывал: **предложивший**, если он крот и в составе.
3. Иначе крот ближе к первому месту (индекс 0 в `seatingOrder`).

На 7–8 игроках в 4-м раунде `requiredSabotages == 2`, поэтому саботируют первые двое из этого списка. Иначе одного саботажа полиции хватит для успеха рейда.

`priorSaboteursFromHistory` не подглядывает в скрытые карты. Он проигрывает прошлые рейды той же конвенцией; если публичный `k > 0`, отмечаются первые `k` назначенных. Это общая легенда стола «кто уже срывал», в том числе для третьего крота, которого не было в том рейде.

## Примеры (5 игроков, наблюдатель `C`, кроты среди `A,B,D,E`)

**Два саботажа на `[A,B]`.** Во всех мирах кроме `{A,B}` `m < 2` → правдоподобие 0. `P({A,B}) = 1`. Единственная тройка с `C` и `P_clean = 1` — `{C,D,E}`.

**Один саботаж на `[A,B]`.** `{D,E}` даёт `m = 0` → 0. `{A,B}` живёт с биномиальным весом `2 α (1−α)`, не с нулём. Смешанные пары (`{A,D}`, …) — вес `α`. `{C,A,B}` и `{C,D,E}` обе плохи; смешанные тройки вроде `{C,A,D}` чище.

**Ноль саботажей.** Миры с кротами на составе худеют на `(1−α)^m`, но не удаляются. Мода — `{D,E}` (никто из рейда).
